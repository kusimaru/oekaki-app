# お絵かきツール(叩き台)

PC と iPad で同じキャンバスを扱える Web ベースのお絵かきアプリです。
Vite + TypeScript、フレームワークなし。PWA としてホーム画面に追加できます。

## 起動

```bash
npm install
npm run dev        # http://localhost:5173 (--host 付きなので同じ Wi-Fi の iPad からも開ける)
npm run build      # dist/ に静的ファイルを出力(GitHub Pages 等にそのまま置ける)
```

## できること

| 機能 | 内容 |
|---|---|
| キャンバス | 新規作成時に名前・サイズ・形式(ビットマップ / ベジェ)を決める。形式は後から変更不可 |
| ライブラリ | ノートブック › セクション › 画像 の 3 階層で管理(左上「ライブラリ」)。セクションは名前で色が決まる。画像の名前変更・移動・削除、ノートブック / セクションの追加・名前変更・削除。閉じた画像もライブラリに残る |
| タブ | 開いている画像をタブで切り替え(上部のタブバー、「＋」で新規、「×」で閉じる = ライブラリに残る、ダブルタップで名前変更、Ctrl+PageUp / PageDown で切替) |
| レイヤー | 追加・削除・並べ替え(行の左端「≡」をドラッグ、または上へ / 下へ)・表示切替・ロック(🔒 書き込み禁止)・不透明度・名前変更・複数選択(Ctrl+クリック / Shift+クリック / 「複数」ボタン)・結合 |
| ボスが来た | ツールバー最下部の「ボス」ボタンで画面全体を真っ黒にして隠す。同じ位置のボタンをもう一度押すと戻る。隠している間はブラウザのタブ名も「Untitled」になる |
| 色 | 基本 12 色 + 登録色(プロジェクトに保存)。不透明度つき |
| ツール | 選択(矩形)、投げ縄、移動、回転、拡大縮小、ペン、消しゴム、バケツ、スポイト、直線、四角形、円、手のひら |
| 保存 | プロジェクト JSON(レイヤー保持)、PNG、PSD(レイヤー保持)、SVG(レイヤー = `<g>`) |
| 開く | プロジェクト JSON、画像(PNG / JPEG / WebP / GIF / BMP / SVG / AVIF)、PSD(レイヤー構成を保持、フォルダは展開)。キャンバスへのドラッグ&ドロップでも可。いずれも新しいタブになる |
| 同期 | GitHub リポジトリに直接コミット(サーバー不要)。自動プッシュ / 定期プル |
| 入力 | Apple Pencil の筆圧、ピンチズーム、2 本指パン、ホイール |

### ビットマップとベジェの違い

- ビットマップ: ペンはピクセル描画。消しゴムは透明化。バケツは塗りつぶし。移動 / 回転 / 自由変形は選択範囲(なければレイヤー全体)を浮動状態にして変形し、Enter で確定。
- 移動ツール(V / Ctrl+T)を選ぶと、Photoshop の「バウンディングボックスを表示」と同じく、選択範囲があればその範囲に、なければ描かれている範囲に枠が出る。角のハンドルで縦横比を保って拡大縮小(Shift で自由な比率)、辺のハンドルで一方向、Alt で中心基準。枠の外をドラッグで回転(Shift で 15° 刻み)、枠の中をドラッグで移動。他のツールに切り替える / Enter / 「確定」/ 枠内ダブルクリックで確定、Esc で取り消し。何も描かれていないレイヤーでは、ドラッグで囲んだ範囲に枠が出る。ベジェでは選択中の図形(未選択ならクリックした図形、またはドラッグで囲んだ図形)が対象。
- ベジェ: ペンはフリーハンドを間引いて滑らかなベジェパスにする。消しゴムは触れたパスを削除。バケツはクリックした図形の塗りを変更。選択ツールで図形をクリック → ドラッグで移動。回転 / 拡縮は選択図形の中心基準。

### 書き出し

- PSD: `ag-psd` で生成。レイヤー名 / 不透明度 / 表示状態を保持。ベジェレイヤーはラスタ化される。
- SVG: 各レイヤーが `<g id="レイヤー名" opacity="…">`。Illustrator で開くとグループとして読み込まれる(レイヤーパネルに分けたい場合は Illustrator 側で「グループをレイヤーに変換」)。ビットマップレイヤーは `<image>` 埋め込み。

## GitHub 同期の設定

1. GitHub で同期用リポジトリを作る(private 推奨)。
2. Settings → Developer settings → Personal access tokens → **Fine-grained tokens** で、そのリポジトリだけに `Contents: Read and write` を許可したトークンを作る。
3. アプリ右上の「GitHub」ボタンで、トークン / オーナー / リポジトリ / ブランチを入力して保存。「接続テスト」で確認できます。
4. 同期はタブバー右のボタンを押したときだけ行われます(既定)。相手の更新があるかは 30 秒ごとに確認して、タブに ↓ の印を出します。
5. 設定の「自動同期」をオンにすると、描く手が止まって 4 秒後に自動で送り、相手の更新を自動で受け取ります(実験的。作業中に絵が入れ替わることがあります)。

リポジトリには `タブ名/project.json` と `タブ名/layers/<id>.png` が入ります。タブ名がフォルダ名です。PSD はローカル書き出し専用です。

### 送る / 受け取るボタン

左のツールバーの一番下に、色の違う 2 つの大きなボタンがあります。迷ったときはこれを押せば必ずその通りになります。

- **送る(オレンジ、上向き矢印):** このタブの絵で GitHub 側を上書きします。
- **受け取る(青、下向き矢印):** GitHub の絵でこのタブを上書きします(この端末の未送信の変更は消えます)。

PC と iPad の両方で同じ絵を変更してしまった場合(未送信 ● と相手の更新 ↓ が同時に付いた状態)は、「どちらを残すかボタンで選んでください」と表示し、2 つのボタンが点滅します。押した方が最新になります。

まだ何も描いていない新しいタブは、GitHub に同じ名前の絵があれば自動で受け取ります(何も失われないため)。

タブ名の横の印: ✓ 送信済み / ● 未送信の変更あり / ↓ 相手の更新あり。画面上部には最後に更新した端末と時刻(例: iPad 3 分前)が出ます。

トークンは `localStorage` に平文で保存されます。共有端末では使わないでください。

## PC でアプリとして使う

Chrome / Edge で公開 URL を開き、アドレスバー右端の「インストール」アイコン(または メニュー →「アプリをインストール」/「アプリとしてインストール」)を選ぶと、単独ウィンドウのアプリになります。デスクトップやスタートメニューから起動でき、データは同じブラウザのものを共有します。

## iPad で使う

1. `npm run build` した `dist/` を GitHub Pages などの HTTPS で公開する(`vite.config.ts` の `base` は相対パスなのでサブパス配信でも動く)。
2. Safari で開き、共有 → ホーム画面に追加。
3. Apple Pencil を使うと自動で「指でも描く」が OFF になり、指はパン専用になります(サイドバーで戻せます)。

開発中は `npm run dev` を PC で動かし、iPad から `http://<PCのIP>:5173` を開いても試せます。

## ツールバー

- アイコンは Photoshop 風の白線アイコン(形は [Lucide Icons](https://lucide.dev)(ISC License)をベースに調整。Adobe のアイコン画像は使っていません)。
- ボタンをドラッグ&ドロップで並べ替えできます。順序はブラウザに保存されます。
- ブラシ / 消しゴム使用中は、描く線と同じ太さの円がカーソルになります(ズームに追従)。
- 塗りつぶしは Photoshop と同じく既定で「現在のレイヤー」だけを参照します。上のレイヤーの線を境界にしたい場合は「塗りつぶしで全レイヤーを参照」を ON にしてください。

## 構成

```
index.html          UI の骨組み
src/main.ts         状態・ビュー操作・UI 配線・GitHub 同期ループ
src/tools.ts        全ツールの実装(ビットマップ / ベジェ両対応)
src/document.ts     ドキュメント / レイヤー / 合成
src/vector.ts       ベジェパス演算(間引き、平滑化、ヒット判定、SVG 変換)
src/raster.ts       選択範囲マスク、塗りつぶし
src/history.ts      元に戻す / やり直し
src/project.ts      プロジェクト JSON の読み書き
src/exporters.ts    PNG / PSD / SVG 書き出し
src/github.ts       GitHub Git Data API クライアント
```

## 編集ボタン(iPad などキーボードがない環境向け)

サイドバー上部の「編集」に、カット / コピー / ペースト / 消去 / 全選択 / 選択解除 / 確定 のボタンがあります。

- ビットマップ: 選択範囲(なければレイヤー全体)をコピーし、ペーストすると新しいレイヤー「ペースト」に元の位置で貼り付き、移動ツールに切り替わります。
- ベジェ: 選択した図形をコピーし、ペーストすると同じレイヤーに少しずらして貼り付きます(別レイヤーへは同じ位置)。
- クリップボードはアプリ内専用です。他のアプリとの画像のやり取りは PNG 書き出し / プロジェクトを開くで行ってください。

## 既知の制限(叩き台のため)

- 元に戻すの対象は、レイヤーの中身の変更と、レイヤーの追加 / 削除 / 並べ替え / ペースト。表示切替・不透明度・名前変更は戻せない。
- 同期はレイヤー単位のマージをせず、競合時は手動選択。
- ベジェの消しゴムはパス単位の削除(部分消去なし)。ベジェのバケツは図形の塗り変更のみ。
- ベジェパスのアンカー編集(ハンドル操作)は未実装。
- ローカル自動保存は `localStorage`(容量制限あり。大きなキャンバスでは保存されないことがある)。
- オフライン用の Service Worker は未導入(ホーム画面追加はできるが、初回表示にはネット接続が必要)。
